XML + XSLT REPORT - RUN STEPS
=============================
Files:
- books.xml
- books.xsl

Keep both files together.

Expected output:
- heading "Book Catalog Report"
- total book count
- details for each book

The total is generated by:
count(catalog/book)

If local XSLT is blocked, use:
python -m http.server 8000
then open http://localhost:8000/books.xml
from this folder, if Python is available.
